# 排版模式表格翻译

状态：已实现全局开关、历史文献恢复和表格补翻。日期：2026-10-23。

## 范围与入口

“翻译表格”复选框位于排版阅读工具栏“同步滚动”右侧，读写全局首选项 `translateTables`，初始默认勾选。工作台设置和 Zotero 偏好设置均不再保留重复入口。打开的其他工作台接收全局偏好变更，按同一偏好显示。

首次排版翻译仍让表格文字与正文共用现有翻译批次。阅读器同时保留原图与译表节点，切换开关只改变表格自身的可见性，不重建整篇页面、不重新适配正文。首次显示译表时仅测量表格；表框尺寸和字体加载状态未变时复用测量。正文排版缓存不因开关改变而失效，PDF 标识仍区分原图与译表。保留磁盘上的正文与译表；关闭开关后再次全文翻译也不清空译表缓存。

每篇文献的 `layoutTableDisplay` 只记录上次显示状态，用于历史冲突提示，不覆盖全局偏好。打开此前显示译表的文献且全局关闭时，在启动通知和已有弹窗结束后询问是否重新开启全局开关；拒绝则记录为显示原图，并询问是否更新已有 PDF。已有译表但没有显示记录的旧文献按此前开启处理。普通重开不主动补翻、不反复询问已经拒绝的历史状态。

用户勾选后逐表检查当前语言、源指纹、表格结构和完整译文。缓存完整时直接显示；缺失时询问是否补翻，仅提交缺失的表格记录，完整 Markdown 全文作为上下文，不提交正文翻译目标。沿用现有 API／网页翻译路由和单元格保护协议；机翻沿用单元格翻译服务，不使用模型上下文。请求不静默截断全文，超出提供商容量时保留已有结果并展示错误。也可在该询问中选择手动翻译，复制包含全文与缺失表格的命令，导入时校验来源。新结果按整表保存，缺失／失败表格保留原图；已有有效译表不被不完整回答覆盖，正文译文及完成元数据不变。

补翻时可取消勾选；已提交请求按原输入完成并缓存，完成后不重新开启开关。弹窗队列等待正在运行的任务、打印、欢迎通知、公告及其他模态窗口结束；排队操作绑定文献、语言和偏好版本，过时操作不应用到新的状态。

实际切换译表／原图或补翻产生新的可见译表后，存在旧 PDF 时记录 `tablePDFPending` 并询问是否更新条目下已有的译文 PDF 和对照 PDF。确认没有已有附件时不询问更新，并清除历史待更新标记，避免阻挡后续正文翻译完成后的首次生成；旧版仅有同名附件的情况也能识别。拒绝后保留旧 PDF，自动生成路径在本次会话和下次重开均不能绕过该决定；以后再次切换仍会询问。PDF 标识反映当前可见表格状态，新附件全部生成成功后才处理旧附件，有批注或笔记的旧附件保留。打印期间不切换显示；等待打印就绪时若显示版本改变，放弃该次旧版本自动导出。

支持普通文字、数值与结构明确的合并单元格表格。API、DeepSeek 网页端和联网／Edge 机翻均接入现有翻译服务；本次真实请求验收使用 Gemini。手动复制命令、粘贴回答、多轮合并和续译均已接入表格；每张表继续作为同一轮命令中的一条记录，手动流程不调用模型。智能体单篇任务支持 `translateTables` 单次选项，批量任务沿用相同流水线及当前配置。

## 提取与保护

`src/layout-tables.js` 从当前 `layout.json` 的 `preproc_blocks` 提取 `table_body` HTML，通过宿主 DOMParser 构建规则化网格。新 Paddle 解析结果在 `ParserModel.projectLayout` 中携带表格 HTML；旧缓存缺少 HTML 时，从保留的 `parsed-document.v1.json` 中恢复。仅对页面尺寸、表格 ID、坐标及图片路径均一致且来源唯一的表格在内存中补齐，不改写磁盘缓存或源指纹；缺少可靠结构时保留原图。恢复后的表格进入现有共享翻译请求与译表缓存管道。

只接收单张表格、合法跨度、无重叠且无缺口的网格。保留行列与 rowspan／colspan，不推断原服务遗漏的合并关系。含图片、SVG、嵌套表格或不支持元素的区域跳过。已有 image／chart 分类、Figure 图注、森林图表头和紧邻图形证据可阻止替换；这些筛选不能证明所有合法 HTML 都与原图一致。

数值、编号、公式与上下标转换为单元格内部的受保护占位符，译后按原内容恢复。纯数值、明确单位、纯公式与编号不发送。原本为空的单元格不发送并保持为空。仅检查待翻译文字非空和占位符完整性，不限制译文长度或换行数量，也不额外推断数字是否变化；占位符在本地恢复数值与公式。编号或占位符缺失时保留原表，不影响正文结果。

## 翻译协议与存储

每张表作为一个 `table_cells` 记录，与正文放入同一批输入；每张表只有一个短 ID，单元格使用 `[数字索引, 文字]`。模型在同一个 `translations` 数组中返回表格的 `cells` 数组，不生成 HTML、坐标或合并关系。表题及同批正文提供上下文，纯数值和公式不重复发送。

取消原有逐表请求和每 80 格／6000 字符的表格专用拆批。标准、分块与 DeepSeek 快速模式均沿用原有文档分组规则；只有内容达到原有分组上限时才自然增加批次。联网／Edge 机翻将表格单元格加入同一次 `translateRecords` 调用。

表格缺失、重复索引、保护内容损坏或单元格返回不完整时保留原表，不因表格问题增加专用重试。完整、有效的返回即使与原文完全相同也保存并显示为译表，视为已完成，后续不重复提示补翻；不根据文字是否变化推断模型是否执行了翻译。正文原有校对机制保持不变。

表格返回不再经过正文专用的公式引用及行内文本修正规则，API／网页的表格 JSON 和机翻的单元格返回均保留校验通过的原始文字。源结构筛选发生在发送前；格式／占位符校验发生在接收时；空间不足只导致显示原图，已经保存的有效译表不会因此删除。

手动命令使用 JSON Lines，正文返回 `{id,text}`，表格返回 `{id,cells}`。完整的表格记录可跨轮保留，续译只包含尚未收到的记录。表格 ID 绑定本次布局源指纹，重新解析后的旧回答不会套用到新的表格；损坏或截断的表格记录不覆盖已经合并的有效结果。正文完整而表格失败时沿用原图，不强制增加表格专用补译轮次。

完成的表格按整表原子写入：

```text
layout-translation/table-translations.<语言>.v1.json
```

文件保存源布局指纹、规则化网格、保护内容和逐格译文。相同来源的完整译表可复用；强制重译重新请求。发布前核对布局来源，取消或失败不发布半张表。

正文 `translations.<语言>.json`、正文完成状态与源解析文件不加入表格单元格。译表在基础排版模型构建之后附加，不写进原有 compiled-model 缓存；显示缓存和 PDF 附件去重标识反映当前可见的译表摘要，关闭时使用原表状态。仅表格内容变化也能独立更新 PDF，但需经过上述更新确认。仅有表格译文的文献同样具有译文状态、导出能力和重新翻译入口。

## 显示

原文侧保持原表。译文侧用本地代码重建安全 HTML，不执行模型返回的 HTML。保留原截图，先在原 bbox 内按内容测量最小列宽与自然列宽，尝试原生自动分列、按内容分列和均衡分列；合并格参与浏览器的实际测量。译表宽高均填满原 bbox；浏览器在行间分配剩余高度，不要求内部行线逐一重合。上下内边距固定为 0.8 个 PDF 坐标单位（随视图缩放），行高倍率固定为 1.15。字号从 9 以 0.5 为步长逐步缩小到 3，每个字号先尝试列宽适配，不再压缩上下留白。允许文字换行，保护数值与公式不随意拆断，发布前检查受保护内容是否越过所属单元格。

横向或纵向放不下时整表保留原图，不推挤正文、不改变正文统一字号、不使用译表内部滚动条。单击表格复用图片、公式同类的模态预览窗口，按宽度适配，短表水平、垂直居中，长表从顶部开始并允许纵向滚动、缩放和拖动。工具栏提供在对话中提问、复制表格和一个导出 HTML 按钮。提问只添加原图，不附带文字；没有可用原图时不提供该操作。复制同时写入保留合并关系的 HTML 与 TSV，成功后提示粘贴到 Excel 查看。导出时选择一次文件夹，将原文和译文分别保存为 `*-original.html` 与 `*-translation.html`；同名已有文件会保留，新导出自动编号。原文由已有表格源单元格恢复，不经过 AI，也不改写缓存。两个 HTML 均为独立文件，公式使用 MathML，不依赖插件资源或联网脚本。阅读器和现有导出快照使用同一份 DOM 选择结果。

## 验证与限制

运行时测试覆盖网格、合并格、公式／数值／编号保护、不安全结构、森林图证据、短索引、共享请求次数、大表不独立拆批、缓存复用、来源变化、取消和 Paddle 结构投影。另覆盖手动命令、JSONL／旧聚合格式、截断回答恢复、多轮合并、续译、导入、来源绑定、关闭选项、纯表格状态与导出判断，以及网页／机翻路由和智能体选项传递。收尾运行 `npm run validate`。

隔离 Zotero 10 使用真实 Gemini 请求验证了正文和表格合并：一次模型请求同时返回 2 个正文块与含 29 个单元格的参数表；验证正常宽度、缩小视图、空间不足时原图回退与完整译表窗口。后续在 Chromium 和隔离 Zotero 10 中验证了留白压缩、密集表、合并格和不可容纳内容的回退；Chromium 另验证了列宽重分配、50%／200% 缩放和含 7 个公式的真实表格。隔离 Zotero 10 另验证了手动正文与表格同轮导入、续译不重复表格和纯表格文献，模型调用数为 0。没有据此宣称任意科研表格都能正确恢复，也未完成所有提供商和 PDF 输出的视觉验收。

首版不拼接跨页表、不翻译纯图片表格、不恢复森林图、不复刻原始字体与线条，也不保证识别出解析器已经丢失的内容。
