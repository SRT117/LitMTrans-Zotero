## Audit notes

- The npm and Cargo license folders preserve available package `LICENSE` and
  `NOTICE` files; the XPI builders verify that every file under
  `assets/vendor/licenses/` is present in the archive.
- `docs/licensing/acquisition-runtime.md` records dynamic-download sources and
  the platform validation boundary. A dynamically installed package is not an
  XPI-bundled dependency.
- No legal conclusion is made about distributing the GPL/FTL CAJ component
  alongside the MIT-licensed first-party source or about downstream duties for
  dynamically installed Python dependencies.
